## What is *not* in this repository

The two official Sky Mavis kits are **excluded** by `.gitignore`:

```
/unity-axie-gtk2d/
/axie-origins-asset-kit/
```

`axie-origins-asset-kit/LICENSE.md` states that the kit is a Vibeathon builder
resource and "not an open-source dump", and that Epic Toon FX and other
third-party Unity Asset Store packages must not be redistributed. This project
therefore never re-publishes the kits. It converts only the files it actually
plays — 19 of the 20 starter Axies, 20 chimeras, 23 of the 107 VFX atlases and
28 of the 130 sound effects — into `axie-td/public/`, and ships those inside the
game build. No Epic Toon FX file, no shop/home/sticker atlas, no HMAC key and no
Firebase config is present.

`axie-td/tools/copy-assets.mjs` is the only path from a kit into this project.
Anyone with both kits checked out next to this repository can reproduce
`axie-td/public/` byte for byte with `npm run assets` (it needs `ffmpeg` on the
PATH).

## Fonts

No web font is bundled. The stylesheet asks for Fredoka first and falls back to
Trebuchet MS, then to the platform's `system-ui`. Fredoka is not shipped, not
downloaded and not hot-linked, so no font licence applies to this build.

## Original content

Level layouts, wave scripts, balance numbers, class auras, all UI text, the
board rendering and the whole TypeScript codebase were produced for this entry.
`axie-td/data/*.json` is machine-generated by `axie-td/tools/gen-data.mjs` and is
never hand-edited.
